POB쇼핑리스트 개인정보처리방침

시행일: 2026년 11월 10일

POB쇼핑리스트(이하 "확장 프로그램")는 Path of Building 빌드 링크의 장착 아이템을 Path of Exile 카카오 거래소 검색 주소로 만들어 크롬 즐겨찾기에 저장하는 크롬 확장 프로그램입니다. 이 확장 프로그램은 사용자의 개인 정보를 수집, 저장, 전송하지 않습니다.

1. 수집하는 개인 정보

수집하는 개인 정보가 없습니다. 이름, 이메일, 계정 정보, 방문 기록, 위치 등 어떤 개인 정보도 수집하지 않으며, 개발자의 서버로 데이터를 보내지 않습니다. 개발자는 별도의 서버를 운영하지 않습니다.

2. 브라우저에 저장하는 정보

아래 정보는 사용자의 브라우저(chrome.storage) 안에만 저장되며, 외부로 보내지 않습니다.

  • 검색 옵션 설정과 선택한 리그
  • 거래소의 공개 데이터(리그 목록, 옵션 목록, 아이템 이름 목록)의 임시 사본. 매번 다시 받지 않도록 최대 3일간 보관합니다.

확장 프로그램을 삭제하면 이 정보도 함께 삭제됩니다.

3. 외부 사이트와의 통신

확장 프로그램은 기능에 필요한 아래 사이트에서 데이터를 읽어 오기만 합니다.

pobb.in, pastebin.com, poe.ninja사용자가 붙여 넣은 빌드 공유 링크에서 빌드 코드를 받아 옵니다.
poe.kakaogames.com카카오 거래소의 공개 데이터(리그 목록, 한글 아이템 이름 목록)를 받아 옵니다.
www.pathofexile.com아이템 옵션을 맞추기 위해 공개된 영어 옵션 목록과 아이템 목록을 받아 옵니다.

이 과정에서 사용자를 식별할 수 있는 정보는 보내지 않습니다. 각 사이트의 정보 처리는 해당 사이트의 개인정보처리방침을 따릅니다.

4. 즐겨찾기 사용

사용자가 [즐겨찾기 만들기]를 누를 때만 북마크바의 "POB쇼핑리스트" 폴더에 즐겨찾기를 만들고, 리그 변경 기능을 쓸 때만 이 폴더 안의 즐겨찾기 주소를 수정합니다. 그 밖의 즐겨찾기는 읽거나 수정하지 않습니다.

5. 제3자 제공 및 광고

개인 정보를 수집하지 않으므로 제3자에게 제공하거나 판매하는 정보가 없습니다. 분석 도구와 광고를 사용하지 않습니다.

6. 방침의 변경

이 방침이 바뀌면 이 페이지에 바뀐 내용과 시행일을 게시합니다.
